# 第 03 课 · 按键切换实测（非阻塞消抖修复后）

## 测试方法
串口持续记录 90 s，期间依次按下 BOOT 6 次。

## 结果：6 次按下 → 6 次切换，无丢失、无重复

```
I (61721) SELFTEST: KEY: 第 1 次按下（60976 ms）→ 模式：常亮
I (63638) SELFTEST: KEY: 第 2 次按下（62893 ms）→ 模式：呼吸灯
I (65981) SELFTEST: KEY: 第 3 次按下（65236 ms）→ 模式：1Hz 闪烁
I (79411) SELFTEST: KEY: 第 4 次按下（78666 ms）→ 模式：常亮
I (83918) SELFTEST: KEY: 第 5 次按下（83173 ms）→ 模式：呼吸灯
I (85141) SELFTEST: KEY: 第 6 次按下（84396 ms）→ 模式：1Hz 闪烁
```

## 修复前后对比

| | 修复前 | 修复后 |
|---|---|---|
| 去抖方式 | `esp_rom_delay_us(20000)` 阻塞 20 ms，且先清 `key_up` 再复检 | 10 ms 采样，连续 2 次一致才认跳变 |
| 短按（<20 ms） | **被丢弃**，表现为"第一次按没反应" | 正常识别 |
| 任务影响 | 每次按键阻塞 20 ms | 不阻塞 |
| 可观测性 | 无按键日志 | 每次按下打印序号 / 时间戳 / 目标模式 |

## 模式顺序
`1Hz 闪烁 → 常亮 → 呼吸灯 → 1Hz 闪烁`，三步一循环；
从闪烁到呼吸灯需要按 **2 次**（两次状态转换），这是设计如此，不是丢按。
