## 课后作业：呼吸灯

- LEDC 定时器 5 kHz、10 位分辨率（1024 级，满足 ≥32 级要求）
- 一个周期 2.5 s（落在 2~3 s 要求内），占空比 0 → 最大 → 0
- 亮度做 gamma 校正（γ = 2.2），避免"前段变化快、后段不动"
- 每个周期串口打印一次 `breath cycle = n`，便于与示波器对时

## 模式切换

上电默认 1Hz 闪烁，短按 BOOT 键循环切换：

```
1Hz 闪烁 → 常亮 → 呼吸灯 → 1Hz 闪烁 ...
```

每次切换都会打印当前模式。

## 修正记录（2026-11-21 14:33）

**现象**：呼吸灯肉眼可见台阶与跳变，且感觉周期短于 2 s。

**原因**：
1. 分辨率只有 10 位（1024 级），刷新周期 20 ms —— 一个 2.5 s 周期内只有 125 次占空比更新，中高亮段每步跨度大，形成"台阶"；
2. 曲线用三角波 + gamma 2.2：亮度被压缩到峰值附近很短的一段，大部分时间接近全暗，看起来像"闪一下"，因此**感觉**周期比实际短。

**修正**：

| 项 | 修正前 | 修正后 |
|---|---|---|
| 分辨率 | 10 位（1024 级） | **12 位（4096 级）**（5 kHz 下上限为 13 位） |
| 刷新周期 | 20 ms（125 级/周期） | **10 ms（250 级/周期）** |
| 曲线 | 三角波 + gamma 2.2 | **正弦 0.5−0.5cos(2πt/T)**，两端导数为 0，无拐点 |
| 周期定义 | 取模 2500 ms | 同上，并按周期序号打印对时 |

**实测（串口时间戳，硬件复位后连续 4 个周期）**：

```
I (3444) SELFTEST: breath cycle = 1
I (5944) SELFTEST: breath cycle = 2
I (8444) SELFTEST: breath cycle = 3
I (10944) SELFTEST: breath cycle = 4
```

相邻间隔均为 **2500 ms**，与设定一致；每个周期 250 级占空比变化，远高于作业要求的 32 级。
